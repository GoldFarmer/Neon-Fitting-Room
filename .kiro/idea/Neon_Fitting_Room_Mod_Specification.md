# Neon Fitting Room — Product Idea

Neon Fitting Room makes outfit fitting feel continuous between Equipment-EX Wardrobe and Cyberpunk
2077 Photo Mode. It provides fast outfit navigation and temporary item-level preview on Photo
Mode's fake puppet, with deterministic reset behavior and synchronization with Equipment-EX's
existing outfit selector.

The authoritative implementation plan lives in `.kiro/specs/neon-fitting-room/`.
